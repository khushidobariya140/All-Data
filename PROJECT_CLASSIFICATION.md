## Needs Manual Review

The following projects have minor ambiguities or duplicates and are noted below for complete transparency:

1. **`Final Project` vs `Final_ Project`**
   - **Primary Category:** `Python-Projects`
   - **Reason:** Both directories contain `final_project.ipynb` and `student_performance_dataset.csv`. `Final_ Project` contains an additional file `cleaned_student_performance.csv`.
   - **Recommendation:** Keep both in `Python-Projects` as distinct project folders (`Final Project` and `Final_ Project`) so zero work or files are lost.

2. **`DAX` vs `DAX DEPO`**
   - **Primary Category:** `PowerBI-Projects`
   - **Reason:** Both folders contain `DAX DEPO.pbix` and identical dimension/fact Excel files. `DAX DEPO` also contains `DAX_Depo_Sample_Datasets.xlsx`.
   - **Recommendation:** Preserve both folders under `PowerBI-Projects/`.

3. **`PRACTICAL EXAM` vs `STUDENT PERFORMANCE DASHBOARD` vs Standalone `PRACTICAL EXAM.pbix`**
   - **Primary Category:** `PowerBI-Projects`
   - **Reason:** `PRACTICAL EXAM` and `STUDENT PERFORMANCE DASHBOARD` share identical Excel data source files (`Attendance.xlsx`, `Scores.xlsx`, etc.). `STUDENT PERFORMANCE DASHBOARD` contains `STUDENT PERFORMANCE DASHBOARD.pbix` while `PRACTICAL EXAM` contains `PRACTICAL EXAM.pbix`.
   - **Recommendation:** Keep all projects preserved in `PowerBI-Projects/` in their respective directories/files.

4. **`Calculative Foundation` & `Descriptive Booster` & `Spread Locator` & `DERIVABLE JUDGEMENT` & `Expectation Decider` & `Mathematics_Final_Practical`**
   - **Primary Category:** `Statistics-Projects`
   - **Secondary Category:** `Python-Projects`
   - **Reason:** These projects use Jupyter Notebooks and Python code to execute statistical theory, probability, Z-tests, T-tests, and data distributions. Categorizing them under `Statistics-Projects` highlights statistical subject mastery.

5. **`Customer Purchase Behavior Analyzer`**
   - **Primary Category:** `Data-Preprocessing-Projects`
   - **Secondary Category:** `Python-Projects`
   - **Reason:** The notebook focuses primarily on data imputation, scaling, feature engineering, and outlier handling.
