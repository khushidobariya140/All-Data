# Python Projects

A curated collection of Python-based data analysis, data profiling, exploratory data analysis (EDA), and automation projects.

## Projects Overview

| Project Name | Description | Key Technologies & Libraries |
| :--- | :--- | :--- |
| **Analyzer** | Script for structured dataset inspection and data analysis. | Python |
| **Data Profiler** | Comprehensive data profiling pipeline with multi-source acquisition (SQLite, JSON, CSV), automated HTML profile report generation, and exploratory analysis. | Python, Pandas, SQLite, HTML Report Generator |
| **Final Project** | Exploratory Data Analysis (EDA) on student performance data evaluating test scores, demographics, and key patterns. | Python, Pandas, Matplotlib, Seaborn |
| **Final_ Project** | Enhanced student performance analytics notebook covering dataset cleaning and visualizations. | Python, Pandas, Matplotlib, Seaborn |
| **TechWar** | Indian retail sales data analysis exploring retail trends, order patterns, and customer analytics. | Python, Pandas, Seaborn, Jupyter Notebook |
