# Machine Learning Projects

A collection of Machine Learning projects covering predictive modeling, regression, classification, model evaluation, and feature importance analysis.

## Projects Overview

| Project Name | Description | Machine Learning Stack |
| :--- | :--- | :--- |
| **Houseprice Prediction** | Regression modeling pipeline predicting real estate prices based on property features, location metrics, and physical attributes. Includes dataset preparation, train-test splitting, feature engineering, and model evaluation metrics (RMSE, R²). | Python, Scikit-Learn, Pandas, NumPy, Matplotlib |
