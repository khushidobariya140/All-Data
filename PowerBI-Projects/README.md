# Power BI Projects

A collection of interactive Power BI dashboards, star-schema data models, Power Query ETL pipelines, DAX calculations, and report designs.

## Projects Overview

| Project Name | Description | Key Power BI Features |
| :--- | :--- | :--- |
| **DATA LAVERAGER** | Power Query ETL project focusing on multi-source extraction, data transformation, and cleaning. | Power Query, ETL, Data Integration |
| **DATA MODELER** | Sales analytics report featuring a full star-schema data model (`Sales_Fact`, `Customer_Dim`, `Product_Dim`, `Region_Dim`, `Date_Dim`). | Data Modeling, Star Schema, Relationships |
| **DAX** | Sales & returns analysis report showcasing DAX measures, calculated columns, time intelligence, and matrix visual layouts. | DAX Measures, Time Intelligence |
| **DAX DEPO** | Deep-dive DAX repository report demonstrating custom business metrics, measures, and calculated columns. | DAX, Custom Measures |
| **FINAL PROJECT POWERBI** | Comprehensive Sales & Customer Intelligence Dashboard complete with multi-page reports, executive views, and map visuals. | Multi-page Dashboard, Interactive Visuals |
| **PRACTICAL EXAM** | Attendance, student performance, and behavior analytics dashboard report. | Attendance Metrics, Visual Analytics |
| **STUDENT PERFORMANCE DASHBOARD** | Student performance & attendance tracking dashboard with executive insights. | Power BI Desktop, KPI Cards |
| **Healthcare Dashboard** | Standalone Power BI report for healthcare metrics tracking. | Healthcare Analytics, Visualizations |
| **K Dashboard** | Executive analytics Power BI dashboard report. | Executive Reporting, Visual Insights |
| **ViMAX Sales Analysis** | Comprehensive sales analytics report evaluating sales performance across products and regions. | Sales Analytics, Performance Dashboards |
| **PowerBI Design Assets** | Presentation template background layout and SVG icon assets for custom dashboard styling. | Layout Design, Visual Assets |
