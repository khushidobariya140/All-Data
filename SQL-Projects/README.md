# SQL Projects

A collection of SQL projects focusing on relational database design, schema creation, data manipulation, transformations, and analytical querying.

## Projects Overview

| Project Name | Description | Key SQL Features & Concepts |
| :--- | :--- | :--- |
| **DATA TRANSFORMER** | SQL DDL and DML scripts for data transformation, database setup, table creation, and ETL transformations. | MySQL/SQL, DDL, DML, Data Transformation |
| **E-COMMERCE** | Full E-Commerce Order Management System database. Features schema creation, primary/foreign key constraints, transactional tables, and complex analytical join queries. | MySQL/SQL, Foreign Keys, Joins, Aggregations |
| **FINAL PROJECT** | Database implementation for student performance tracking, featuring relational schema design, table constraints, and aggregation queries. | MySQL/SQL, Relational Modeling, Aggregations |
| **PROJECT1** | Customer database initialization script executing table creation, insertion, data filtering, and update operations. | MySQL/SQL, Data Filtering, CRUD Operations |
