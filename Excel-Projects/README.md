# Excel Projects

A collection of Microsoft Excel analytics workbooks, data models, financial/business spreadsheets, and interactive dashboards.

## Projects Overview

| Project Name | Description | Key Excel Capabilities |
| :--- | :--- | :--- |
| **PR. 2 Analyzer** | Excel dataset analysis workbook featuring structured data modeling, formulas, and summarization. | Excel Formulas, Data Modeling, Pivot Tables |
| **PR. Final Project** | Final comprehensive Excel analytical project workbook containing structured business data. | Excel Analysis, Charting, Formulas |
| **PROJECT1** | Structured business spreadsheet for operational tracking and metrics analysis. | Data Organization, Formulas |
| **Khushi Dashboard** | Interactive executive Excel dashboard workbook for key metrics visualization. | Pivot Tables, Interactive Charts, Dashboards |
