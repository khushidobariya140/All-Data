# Statistics Projects

A collection of statistics and mathematical analysis projects implementing probability distributions, statistical inference, hypothesis testing, correlation, and regression analysis in Python.

## Projects Overview

| Project Name | Description | Statistical Concepts |
| :--- | :--- | :--- |
| **Calculative Foundation** | Foundational mathematical and statistical calculation notebook covering central tendency, dispersion, and matrix operations. | Mean, Variance, Standard Deviation, Matrix Algebra |
| **DERIVABLE JUDGEMENT** | Inferential statistics on health datasets, including hypothesis testing (Z-test, T-test) and confidence intervals. | Hypothesis Testing, Z-Score, T-Test, Confidence Intervals |
| **Descriptive Booster** | Statistical analysis of household income distribution, skewness, kurtosis, and probability density functions. | Descriptive Statistics, Skewness, Kurtosis, Income Distribution |
| **Expectation Decider** | Applied probability project modeling student performance using Binomial and Poisson distributions. | Binomial Distribution, Poisson Distribution, Expected Values |
| **Mathematics Final Practical** | Applied statistical research notebook covering correlation matrix, regression analysis, and distribution modeling. | Correlation, Linear Regression, Statistical Modeling |
| **Spread Locator** | Analysis of transaction dataset spread, standard deviation, Z-score calculations, and normal distribution fitting. | Z-Scores, Normal Distribution, Standard Deviation |
