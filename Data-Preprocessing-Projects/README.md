# Data Preprocessing Projects

A collection of data preprocessing, feature engineering, missing value imputation, outlier handling, and data cleansing workflows in Python.

## Projects Overview

| Project Name | Description | Key Preprocessing Techniques |
| :--- | :--- | :--- |
| **Customer Purchase Behavior Analyzer** | End-to-end preprocessing pipeline for customer purchase data, including feature scaling, encoding, outlier filtering, and EDA. | Missing Imputation, Feature Scaling, Outlier Detection, Encoding |
| **Data Cleanser** | Healthcare dataset cleaning focusing on missing value treatment, KNN imputation, and statistical outlier handling. | KNN Imputation, Outlier Treatment, Data Standardization |
| **Final Project Data Preprocessing & Feature Engineering** | Comprehensive credit risk dataset preprocessing featuring One-Hot Encoding, MinMax/Standard scaling, and feature creation (expanding columns from 15 to 97). | One-Hot Encoding, StandardScaler, MinMaxScaler, Feature Generation |
